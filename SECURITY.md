# Security policy

## Supported versions

Only the latest release of webmin-unbound gets security fixes.

## Reporting a problem

Please report security problems privately with Security > Report a vulnerability
on this repository (GitHub private reporting). Do not open a public issue, and do
not publish details before a fix is released.

Include the module version, the distribution, the Webmin version and the steps to
reproduce the problem.

---

Segnala i problemi di sicurezza in privato con Security > Report a vulnerability di
questo repository. Non aprire una issue pubblica e non pubblicare i dettagli prima
della correzione. Indica la versione del modulo, la distribuzione, la versione di
Webmin e i passi per riprodurre il problema.
